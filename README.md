### 🚀 Featured project

**[AI System Design Interviewer](https://github.com/adwet1908/AI-system-design-interviewer)**
Practice system design interviews against an AI interviewer. You chat with it and draw your architecture on a canvas; it reads your diagram, challenges your choices, moves through interview phases, and scores you at the end.

- 🧠 Claude-powered interviewer that moves through interview phases by calling a tool, with all state held on the server
- 🗺️ React Flow canvas turned into structured JSON the AI can read and question
- ⚡ Streamed replies, plus background scoring that picks itself back up after a server restart
- 💳 Razorpay payments with idempotent, race-safe grants and daily quotas
- ✅ CI with GitHub Actions
